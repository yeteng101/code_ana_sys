### 1. 资源流分析器

输入：

```text
Clang 调用图 graph.json
call_site 文件、行号、snippet、evidence_ids
```

当前提取：

```text
acquire
release
transfer
hold
unresolved path
```

libuv 运行结果：

```text
status: partial
items: 256
evidence: 348
```

资源流 analyzer 不直接写：

```text
memory_leak = true
```

未配对的路径输出：

```text
complete = false
termination_reason = release_not_found / acquire_not_found
```

并保留源码证据和低置信度。

### 2. 同步关系分析器

当前提取：

```text
mutex_lock
rwlock
condition_variable
event_wait
event_notify
thread_join
```

libuv 运行结果：

```text
status: succeeded
items: 32
evidence: 61
```

同一函数、同一资源 key 的 lock → unlock 作为较高置信度的事实；
跨线程通知/等待和 event 关系使用较低置信度，并保留 `unknown`，不直接输出
`deadlock` 或 `race`。

### 3. 怎么运行

  --workspace demo/libuv
